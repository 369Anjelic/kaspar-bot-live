🔑 Claude API Setup

⚠️ Gib nur einen GÜLTIGEN API-Key ein! Der Key wird nur lokal gespeichert.

Um Kaspar zu aktivieren brauchst du einen Claude API Key:

  1. Gehe zu: console.anthropic.com
  2. Login oder erstelle einen kostenlosen Account
  3. Gehe zu "API Keys" Sektion
  4. Klick "Create Key"
  5. Kopiere deinen neuen Key (beginnt mit sk-ant-v3-...)
  6. Füge ihn unten ein und speichere

Der Key wird NUR im Browser-Speicher (localStorage) gespeichert und niemals an externe Server übertragen.
